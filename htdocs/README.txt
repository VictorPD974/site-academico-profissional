COMO PUBLICAR NO INFINITYFREE
1. Crie uma conta no InfinityFree.
2. Crie um site/domínio gratuito.
3. Abra o File Manager ou use FTP.
4. Entre na pasta htdocs.
5. Envie todos os arquivos desta pasta para htdocs.
6. Acesse o endereço fornecido pelo serviço.
